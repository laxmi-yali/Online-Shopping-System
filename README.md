# Online-Shopping-System

## 📌 About the Project
The Online Shopping System is a simple Python-based project that allows users to purchase products through a menu-driven application.
Users can view available products, add products to their shopping cart, remove items, check the total price, and generate a final bill.

## 🎯 Objectives
- Make shopping simple and easy.
- Display available products and prices.
- Manage shopping cart items.
- Calculate the total bill automatically.
- Provide a simple shopping experience.

## ✨ Features
1. View Available Products
2. Add Products to Cart
3. View Shopping Cart
4. Remove Products from Cart
5. Calculate Total Amount
6. Generate Final Bill
7. Exit the Application

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Concepts:** Dictionary, Loops, Conditional Statements, Functions and User Input.

## ▶️ How to Run the Project

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python shopping.py
```

5. Select an option from the menu.
6. Follow the instructions to shop.
